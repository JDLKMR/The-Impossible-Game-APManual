# The Impossible Game Manual APWorld
This is a small Archipelago Manual for the classic sidescrolling game.

## Items
- Unlocks for access to each level

## Checks
- Completing levels
- Completing levels in Practice Mode (if enabled)

## Goal
- Complete every level (non-Practice Mode).

## Notes
- If you complete a level without Practice Mode, you can automatically check off the Practice Mode equivalent of the level as well.
- Any time you complete a level without Practice Mode, be sure to also mark off the (EVENT) check for that level as well, as this is required for it to count toward victory.
- Hooks are used to allow for the YAML option to select which level to start with.
